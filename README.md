# dticket.github.io

## About

This is a simulator for the Deutschland-Ticket. The code is not valid and not scannable.
The Ticket will pass for busses, since they don't check. Any place that scans, doesn't pass (yet).

THIS IS NOT MEANT TO BE USED TO COMMIT CRIMES! PLEASE ONLY USE TO SEE HOW THE TICKET WORKS!
