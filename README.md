# dticket

This is a Deutschland-Ticket Simulator.

The generated Ticket looks real, but can NOT be scanned.
Only serving the purpose of seeing how a real ticket works before buying.

DISCLAIMER: Since there are loads of places where they don't scan tickets (busses, etc.),
and due to the fact that this ticket easily passes an eye inspection,
It has to be mentioned that I (the author) forbid and certainly DON'T ENDORSE illegal use of this ticket.
